# تحديثات إطار البيت (Otmo Frame)

هذا المستودع يحمل تحديثات الإطارات فقط: كل إطار يقرأ `update.json` كل ٦ ساعات تقريباً.

- `update.json` موقّع بمفتاح المطوّر؛ أي تعديل بدونه يرفضه الإطار.
- `files/web-*.zip` صفحات الإطار (تُحمَّل بدون إعادة تثبيت).
- `files/frame-*.apk` التطبيق كاملاً (يُثبَّت بصمت على الإطارات المسجّلة كمالك للجهاز).

لا تُرفع هنا أي بيانات عميل أو رموز.
